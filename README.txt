TaxiPro Sverige – version med 500 unika övningsfrågor

Innehåller 500 unika övningsfrågor i nio ämnesområden. Frågorna är egenproducerade träningsfrågor och inte Trafikverkets officiella provfrågor.

Publicera genom att ladda upp samtliga filer direkt i GitHub-repositoryts rotmapp. Aktivera GitHub Pages via Settings → Pages → Deploy from a branch → main → /(root).

Frågebanken är utbildningsmaterial. Regler kan ändras; kontrollera alltid aktuella bestämmelser hos Transportstyrelsen, Trafikverket och andra ansvariga myndigheter.
